# Cross-team handoffs

Create one handoff file per cross-team task using a short kebab-case task name, for example `docs/agent-handoffs/order-api.md`.

Include:

- Goal and owning leads
- Acceptance criteria and dependencies
- Endpoint method/path and authentication requirements
- Request, response, and error shapes
- Socket.IO events, if applicable
- Decisions still needing confirmation
- Status and verification results

The receiving lead must confirm the contract before assigning implementation. Keep handoffs scoped to the task and update or remove obsolete details when the contract changes.
